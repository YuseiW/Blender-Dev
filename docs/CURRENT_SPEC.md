
# CURRENT_SPEC
# Blender Animation Reference Tool

最終更新: 2026-11-10
対象: YuseiW/Blender-Dev
確認コミット: eec9c644
開発段階: Phase 1完了 / Phase 2開始前

## 1. 研究目的

Blenderを利用したアニメーション制作において、
絵コンテ・レイアウト・原画を現在のフレームと
対応付け、資料参照作業の負担を軽減する。

## 2. 現行システム構成

- Blenderアドオン単体で実装する。
- 独立したWindows GUIアプリは制作しない。
- 画像登録・資料管理・表示をBlender内で完結する。
- リファレンスビュアーにはBlender標準の
  別ウィンドウを利用する。
- 開発言語はPython（Blender API）。

※ 独立Windows GUIの案は廃止済み。
  旧企画書に記載があっても復活させない。

## 3. データ構造

### Project
- プロジェクト名
- FPS（基本24fps）
- 画像プール
- 複数のCut
- 保存先

### ImageAsset
- UID
- 画像名
- ファイルパス

### Cut
- UID
- カット名
- Timeline開始フレーム
- 絵コンテ一覧
- レイアウト一覧
- 原画一覧

### ReferenceItem
- UID
- 参照画像ID
- 表示フレーム数
- 自由記述による指示

## 4. 実装済み機能

- 複数画像のインポート
- Image Pool
- カット追加・削除
- 資料登録・削除・並び替え
- 絵コンテ・レイアウト・原画の切り替え
- 表示フレーム数の設定
- 指示文の入力
- JSON形式でのプロジェクト保存・読み込み
- Timeline手動同期
- Timeline自動同期
- カット・カテゴリ変更時の表示同期
- 対応資料がない場合の画像表示解除
- JSONデータ検証
- 読み込み失敗時のロールバック

Phase 1の自動スモークテスト6項目成功。
UI最終確認もユーザー報告では全項目成功。

## 5. Phase 2：独立ビュアー

### 実装目標

Blenderの別ウィンドウに、現在フレームに
対応する制作資料を表示する。

### 必要機能

- Blender標準ウィンドウの生成
- ビュアーの重複起動防止
- 専用表示先の管理
- 現在フレームとの同期
- カット・カテゴリ切り替えとの同期
- 画像と指示文の同時表示
- 対応資料なし・画像欠損時の表示
- ウィンドウを閉じた場合の安全な処理

### 後続の検討事項

- カメラビュー上への半透明画像表示
- 画像プールのUI改善
- サムネイル表示
- ドラッグ＆ドロップ登録
- 登録済み画像の差し替え

※ 後続項目の優先順位と必須範囲は未確定。

## 6. 現在の制約

- 現在はすべてのImage Editorが同期対象。
- ビュアー専用の表示先管理は未実装。
- JSONには一部のUI選択状態を保存していない。
- Windowsコンソールで日本語が文字化けする。
- chcp 65001は環境でフリーズが発生したため
  使用しない。

## 7. 開発方針

- 既存データ構造を可能な限り維持する。
- UI / Operator / Manager / Dataを分離する。
- 仕様変更はDECISIONS.mdに記録する。
- 実装前後にDEVELOPMENT_LOG.mdを更新する。
- 実装済みと動作確認済みを区別する。
- 古い企画書より現行仕様を優先する。
